# Project guidance

## Design system

Read DESIGN.md before making visual or UI decisions. Keep the approved current TATEL direction: existing coastal imagery and films, navy glass, gold accents, Bodoni Moda, and Manrope. Use the shared theme and text components. The consultation alternatives and four-destination dock were not selected.

Preserve the ticket → accommodation → saved sessions → Explore journey and its explicit completion rules. Keep copy readable at phone widths and enlarged text sizes. During UI review, flag clipping, inaccessible actions, and deviations from DESIGN.md. Material changes to the visual direction need explicit user approval; routine fixes within the approved direction do not.
